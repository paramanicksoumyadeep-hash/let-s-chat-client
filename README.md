# 💬 Let’s Chat – Client (Frontend)

The **Let’s Chat Client** is the frontend of a real-time chat application built using **React** and **Socket.IO Client**.  
It provides a responsive and interactive user interface for real-time messaging.

🚀 **Live App:** https://let-s-chat-client-app.vercel.app/

---

## 🔍 Overview

This client application connects to a Socket.IO-powered backend server to enable real-time, bidirectional communication between users.
